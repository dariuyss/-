# Альфа · Умный кредитный кабинет предпринимателя

Клиентский кабинет и рабочее место андеррайтера в одном приложении. React + Vite + TypeScript + Tailwind CSS + Lucide; FastAPI + SQLAlchemy 2.0 + SQLite. Все данные и банковские операции демонстрационные.

## Запуск всего стека

Установите Docker Engine с Compose v2 или Docker Desktop (Linux containers). Из корня проекта:

```bash
docker compose up --build
```

Дополнительная конфигурация не нужна. После завершения healthcheck:

- Кабинет: **http://localhost:3000**
- Swagger: **http://localhost:8000/docs**
- Проверка API через Nginx: **http://localhost:3000/api/health**

При первой сборке нужен интернет для скачивания бесплатных образов и open-source зависимостей. Во время работы внешние API, CDN, платные сервисы, ключи и подписки не нужны. Шрифты системные, иконки входят в сборку.

Опционально скопируйте `.env.example` в `.env`, чтобы изменить внешние порты. Внутри сети backend всегда доступен как `backend:8000`. Фронтенд обращается к относительному `/api`, поэтому изменение внешнего порта API не требует пересборки интерфейса.

```bash
docker compose ps
docker compose logs -f backend frontend
docker compose restart
docker compose down
```

`down` сохраняет именованный том `credit_data`. БД и документы живут в `/app/data/credit_cabinet.db`; seed при старте не перезаписывает пользовательские решения. `docker compose down -v` удаляет демо-БД и документы — используйте только для осознанного полного сброса. Локальная БД из `backend/` в образ не копируется.

Backend работает от непривилегированного пользователя UID 10001. На новом именованном томе права наследуются от `/app/data` образа. SQLite — встроенная файловая БД backend, отдельный контейнер БД не нужен. WAL, история и файлы документов сохраняются вместе. Один процесс backend; для горизонтального масштабирования потребуется серверная СУБД.

Frontend собирается в `node:20-alpine` с pnpm 10.28.0 и `--frozen-lockfile`; готовые файлы раздает `nginx:alpine`. Nginx проксирует `/api/`, отдает SPA fallback и кеширует хешированные assets. Backend использует `python:3.11-slim`, запускает `uvicorn main:app` через адаптер `container_main.py`. В обоих сервисах есть healthcheck и `restart: unless-stopped`. Frontend запускается после готовности backend; его Compose healthcheck проверяет также API через прокси.

## Что показать жюри

В верхней панели переключаются роль и компания. Настройки роли и ИНН сохраняются в браузере. Для неизвестного ИНН выберите «Ввести свой ИНН» — backend создаст стабильный синтетический профиль.

| Компания | Демо-путь |
| --- | --- |
| 7701111111 · АльфаТех Логистик | Откройте заявку → основной оффер → код демо-SMS → согласие → подписание → FUNDED с поздравлением |
| 7702222222 · Сеть кофеен Бодрость | Сравните запрошенные 10 млн с основным уменьшенным оффером и дополнительным вариантом; любой можно выбрать |
| 7703333333 · СтройМастер | Загрузите выписку и отчетность → заявка возвращается андеррайтеру → переключите роль → откройте досье → одобрите или измените условия |
| 7704444444 · Вектор Торг | Посмотрите отказ, факторы риска и персональные рекомендации по снижению долговой нагрузки |

На дашборде есть выручка, заявки, полученное финансирование, карточка компании и статус ФНС. У каждой новости виден `personalization_reason`: ОКВЭД, статус заявки или финансовые показатели. При смене компании и после операций лента перезапрашивается; в фоне работает опрос каждые 5 секунд, пока вкладка видима. Проверки и скоринг синхронны на backend, поэтому промежуточные этапы отражены в таймлайне и истории, а не искусственно растянутой анимации.

В подборщике задайте цель, сумму, срок и залог, сравните продукты и перейдите к форме. Кнопка автозаполнения получает профиль из `/api/mocks/company-by-inn/{inn}`. Выручку, прибыль, текущие платежи, сумму и срок можно менять. Калькулятор показывает предварительный платёж и DTI. Отправьте заявку или сохраните черновик.

В банковском режиме очередь показывает все компании, поддерживает поиск, фильтры по статусу и Grade A–D. В досье доступны скоринг, DTI, PD, факторы, вкладки ЕГРЮЛ / ФНС / БКИ, скачивание документов и полный audit log. Ручные решения разрешены в соответствующих статусах; нельзя одобрить заявку с незагруженными запрошенными документами. После решения переключитесь в роль клиента — новое состояние появится автоматически.

## Контракты и важные детали

- Клиент использует существующие эндпоинты FastAPI; типы запросов/ответов находятся в `frontend/src/types.ts`, обращения — в `frontend/src/api.ts`.
- Расширение `ApplicationCreate.financial_overrides` необязательно и содержит только `annual_revenue`, `monthly_net_profit`, `current_debt_load`. Старые запросы работают как прежде. Заявленные цифры поступают в скоринг, сохраняются в снимке заявки и аудите, а профиль моков остается неизменным. Новых колонок БД не требуется.
- `current_debt_load` — **ежемесячные платежи**, не остаток долга. DTI = (текущие платежи + предварительный платеж нового кредита) / чистая месячная прибыль.
- Текущий stub рассчитывает ставку 19,5% для всех продуктов. Каталог показывает базовые ставки продуктов; калькулятор явно помечен как предварительный. Финальные условия берутся из оффера API. Изменение выручки поступает в контракт модели; текущие правила stub принимают решение преимущественно по ИНН, прибыли, платежам и флагам задолженности.
- Выбор оффера, запрос кода, подписание и выдача — отдельные API-вызовы. При сбое выдачи после подписания можно повторить только зачисление. Повторная выдача идемпотентна. Реальные SMS не отправляются: код показан в диалоге.
- Лимит документа 10 МиБ; Nginx допускает 11 МиБ с учетом multipart. Файл хранится в SQLite. Все запрошенные документы должны быть загружены для автоматического возврата андеррайтеру.
- `scoring_result` — первоначальный результат stub; актуальное решение банка находится в `status`, `offers`, `history`.
- Даты показываются по Москве. У списка API есть пагинация; интерфейс загружает страницы по 100 элементов.
- Роли — демо-переключатель интерфейса и аудит, а не аутентификация. Реальные внешние проверки, банковские переводы и юридически значимая ПЭП не выполняются.

## Локальная разработка без Docker

Backend, из корня проекта (Python 3.11–3.13):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

Frontend, в другом терминале (Node 20.19+ и pnpm 10.28.0):

```bash
cd frontend
npm install --global pnpm@10.28.0
pnpm install --frozen-lockfile
pnpm dev
```

Vite запускается на http://localhost:3000 и проксирует `/api` в `http://127.0.0.1:8000`. Для прямого доступа можно создать `frontend/.env.local` с `VITE_API_BASE_URL=http://localhost:8000/api`; по умолчанию это не требуется. В Docker локальные `.env` frontend исключены из build context.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest backend.tests.test_api -v
.\.venv\Scripts\python.exe -m pip check
```

```bash
cd frontend
pnpm build
```

Backend-тесты изолированы от пользовательской БД. `pnpm build` проверяет TypeScript и собирает production-статику. Браузерная проверка проводится на отдельной демо-БД.

Проверено при разработке: production-сборка с TypeScript strict/noUnused, все 10 API-тестов, `pip check`,
совместимость frozen lockfile с pnpm 10.28.0, разбор Compose YAML. В браузере проверены дашборд,
смена компании/персонализации, подбор продукта, автозаполнение, ручные финансовые значения и подача,
сравнение офферов, подписание до FUNDED, фильтр Grade D, досье ФНС и audit log.
Автоматизированный файловый диалог браузера завершился ошибкой драйвера, поэтому загрузка документов
и возврат андеррайтеру подтверждены API-тестами, без утверждения об успешной браузерной проверке загрузки.
Docker CLI/Engine в среде разработки отсутствовал: контейнерная сборка, healthcheck внутри контейнеров
и сохранность тома при реальном перезапуске здесь не запускались; для них используйте команды ниже.

Дополнительные проверки Docker на машине с установленным Docker:

```bash
docker compose config --quiet
docker compose up --build --wait
curl http://localhost:3000/api/health
```
